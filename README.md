# 千牛小店获客增长 Skill

> 🌐 Language: [中文](README.md) | [English](README.en.md)
>
> 把「淘宝个人小店的获客优化」变成 AI 可以直接执行的标准流程：**诊断 → 商品提分 → 内容引流 → 自动化批量运营**。
> 全部方法在一个真实在营的实验室仪器 C 店上完整跑通，结论均带 ✅ / ⚠️ / ❌ 实测标记，不是纸上谈兵。

## 为什么会有这个仓库

市面上的淘宝运营内容，讲"概念"的多、给**可执行流程**的少；教人肉操作的 多、教 **AI Agent 替你干** 的更少。

这个仓库把一家小店的日常获客优化拆成了 AI 能照做的 SOP（标准操作流程），装进 Claude Code / ZCode / Cursor 这类 AI 编程助手的技能目录就能用。你只需要说一句"帮我优化全店商品"，剩下的诊断、改标题、补属性、防流量受限，AI 会按流程走完并向你汇报。

## 十个实测发现（先看这个）

1. **「流量受限」的头号元凶是必填属性为空，不是标题。**
   编辑页左侧"优化建议"里的红色 **错误(N)**，大多来自属性必填项（额定电压、驱动方式、材质…）为空。补完再提交，成功页的"流量受限"提示直接消失。实测比改标题更有效。
   → [references/03-attributes.md](references/03-attributes.md)

2. **平台会主动弹 AI 推荐属性，点"确定"就是白赚的填写度。**
   编辑页偶发「商品属性信息更新确定」弹窗（平台 AI 推荐属性值，默认勾选采纳）。实测一个温度探头采纳后属性填写度 27% → 36%，零成本。
   → [references/03-attributes.md](references/03-attributes.md)

3. **导购标题（≤15 汉字）是被普遍忽略的机会位。**
   它是手机推荐流实际展示的标题，大量小店全店为空。→ [references/02-title-optimization.md](references/02-title-optimization.md)

4. **改标题 / 补属性可以整体自动化。**
   千牛自带「商品管家」支持对话式批量改（官方接口，不会点错行）；浏览器 Agent + 视觉复核双通道兜底它做不了的操作。→ [references/05-automation.md](references/05-automation.md)

5. **"缺少商品视频"不用拍摄，主图就能批量产视频。**
   主图 → 3D 卡片轮播（零失败兜底）或 AI 图生视频（必须裁文字区 + 视觉 QC，不合格退轮播版）。实测首批 5 件一天产出、全部上传成功。→ [references/07-product-video.md](references/07-product-video.md)

6. **Agent 谎报成功是常态，但"三句指令"能把批量写入做成可复现。**
   "写完后读回自校验 / 整体赋值不要快捷键 / 一口气完成别停下来确认"——这三句写进任务指令，实测 2/2 真实写入成功；缺校验句的那次谎报"已写入"而截图仍是旧值。→ [references/05-automation.md](references/05-automation.md)

7. **淘宝自己的 AI 搜索（千问）会直接摘引商品规格组答案，销量小不是门槛。**
   AI 答案是"场景分支 + 规格短语摘引"结构：把需求词吃进标题、规格短语独立成行、FAQ 每条 134~167 字成块——实测销量个位数的新店商品在 AI 答案里压过销量近百的老链接。⚠️ 红线：跨一级类目改类目 = 近 30 天销量清零且无法恢复。→ [references/08-geo-qianwen.md](references/08-geo-qianwen.md)

8. **React 后台的自动化终态是 CDP 直连，不是坐标点击。**
   锁屏/远程桌面断开后，截图+坐标方案**静默失效**；CDP（connectOverCDP）不依赖前台焦点、读 DOM 真值。配套四条铁律：locator.fill 代替原生赋值、真实点击代替 el.click()、长中文用 insertText、覆盖层先隐藏再操作。→ [references/05-automation.md](references/05-automation.md)

9. **逛逛图文被拒，八成是图不是文。**
   驳回理由就两类："营销信息过重"（品牌+规格+现货+发货+客服导流，沾一条就高危）和"基础美观不达标"（商品主图自带的全图平铺公司水印=牛皮癣，底部促销横幅，AI 生成图有"低质AI"专项 flag）。解法：正文清到纯知识、商业动线全交"关联商品"；图片用 PIL 渲染 1440×1440 知识图表（非 AI 生成），渲染完 RapidOCR 自检。→ [references/09-guanghe-review-lessons.md](references/09-guanghe-review-lessons.md)

10. **内容全干净仍被"秒拒"？查账号，别再耗编辑机会。**
    逛逛每篇的"编辑重发"次数有限，用完锁死。秒拒=机器初审；若正文零营销、图片全重做仍秒拒，且浏览器出现"账号处于异常状态"标，大概率是账号级风控——去千牛查账号体检，改内容无用。另附 OCR+坐标通道的"编辑重发"全坑：负坐标命名传参、contenteditable 全选靠"计数器归零"验证、上传结果弹窗要点右下角「完成」、定时/立即单选钮靠像素取样验证。→ [references/09-guanghe-review-lessons.md](references/09-guanghe-review-lessons.md)

## 快速开始

**方式一：作为 AI 助手技能安装（推荐）**

```bash
git clone https://github.com/yuyang2230/taobao-shop-growth.git
```

把整个 `taobao-shop-growth` 文件夹复制到你 AI 助手的技能目录（如 Claude Code / ZCode 的 skills 目录），然后在已登录千牛卖家中心的浏览器环境里，把下面任一句子原样发给 AI：

> **中文：** "帮我按 taobao-shop-growth 技能，先给店铺做一次诊断，再优化前 10 件商品。"
>
> **English:** "Using the taobao-shop-growth skill: run a full shop diagnosis first, then optimize the top 10 products (titles + required attributes + video), ledger-driven, and report back."

**方式二：当人工操作手册用**

直接按 [SKILL.md](SKILL.md) 的工作流顺序阅读 references/，照着千牛后台一步步做，不需要任何 AI 也能落地。

## 适用于谁

- 一个人或夫妻档经营的淘宝个人店（C 店），没时间系统学运营
- 店铺有一定年头、商品不少，但流量常年躺平的老店
- B2B / 高客单 / 强型号搜索类目（仪器、设备、工业品、五金）尤其契合
- 想用 AI Agent 接管重复性后台操作的效率型卖家

## 案例店铺

本技能的全部流程在一家真实在营的 **实验室仪器小店** 上验证：玻璃反应釜、旋转蒸发仪、磁力搅拌器及配件，买家多为高校实验室、药厂、化工企业。方法跑通的过程和逐件记录都沉淀在 references 里。商品视频免拍摄管线（07）也在该店跑通：两批累计 9 件商品挂上视频并全部提交成功；站内 GEO（08）落地后重点商品核心词自然排名进入前 2~6。
