为什么会有这个项目

市面上的淘宝运营内容，讲「概念」的多、给可执行流程的少；教人肉操作的多、教 AI Agent 替你干的更少。这个仓库把一家小店的日常获客优化拆成 AI 能照做的 SOP，装进 Claude Code / ZCode / Cursor 这类 AI 编程助手的技能目录就能用——你说一句「帮我优化全店商品」，剩下的诊断、改标题、补属性、防流量受限，AI 按流程走完并向你汇报。

六个实测发现

实测 ✅

「流量受限」头号元凶是必填属性为空

补完属性再提交，「流量受限」提示直接消失，比改标题更有效。

实测 ✅

平台主动弹 AI 推荐属性，点确定就是白赚

实测一个商品属性填写度 27% → 36%，零成本。

机会位

导购标题（≤15 汉字）被普遍忽略

它是手机推荐流实际展示的标题，大量小店全店为空。

自动化

改标题 / 补属性可以整体自动化

千牛「商品管家」对话式批量改 + 浏览器 Agent 双通道兜底。

实测 ✅

「缺少商品视频」不用拍摄

主图 → 3D 轮播 / AI 图生视频 + 视觉 QC，首批 5 件一天产出。

可复现

「三句指令」让批量写入可复现

写后读回自校验 / 整体赋值 / 一口气完成——防 Agent 谎报成功。

工作流

  1. 1️⃣ 店铺诊断
  2. 2️⃣ 标题重写
  3. 3️⃣ 属性补全
  4. 4️⃣ 内容获客
  5. 5️⃣ 商品视频
  6. 6️⃣ 自动化运营

快速开始

把仓库作为技能装进你的 AI 助手（Claude Code / ZCode / Cursor）：

git clone https://github.com/yuyang2230/taobao-shop-growth.git

然后把整句发给 AI（需在已登录千牛卖家中心的浏览器环境）：

帮我按 taobao-shop-growth 技能，先给店铺做一次诊断，再优化前 10 件商品。

不用 AI 也可以：直接按 SKILL.md 的工作流顺序阅读 references/，当人工操作手册用。

适用谁

你的情况为什么适合
一人 / 夫妻档淘宝 C 店没时间系统学运营，SOP 直接照做
有年头、商品不少、流量躺平的老店先诊断根因（多数是属性与内容短板），再逐件提分
B2B / 高客单 / 强型号搜索类目仪器、设备、工业品、五金尤其契合
效率型卖家用 AI Agent 接管重复性后台操作
