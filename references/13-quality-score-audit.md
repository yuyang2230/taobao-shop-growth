# 13 · 质量分全景审计 SOP（基础分/扶优分，2026-09-23 实战）

> 场景：淘宝搜索与 AI 搜索（千问导购）都把质量分当流量闸门。本 SOP 用列表页 3 分钟拉齐全店质量分全景，定位每一件「为什么分低」，直接给出修法。当日实测：全店 74 件，定位出 2 件扶优 67 分（均因缺视频）+ 1 件基础 90（运费补差链接），其余全部 100 或新品未覆盖。

## 1. 双指标语义（先搞清再动手）

| 指标 | 含义 | 什么拉低它 |
|---|---|---|
| 基础分 | 类目属性/图片/标题等硬完整度 | 字段空缺（品牌/型号/材质）、主图不合规 |
| 扶优分 | 转化加持项 | **缺商品视频 = 直接 67 分档**（建议面板会明示）、内容单薄 |
| 未覆盖(nc) | 新品/低流量品未出分 | 正常现象，发售后随流量出分，不用修 |

**判因入口**：编辑页顶栏「优化建议」面板——`错误(n)` 是必改项、`建议(n)` 点开逐条读。实测「缺少商品视频 扶优 影响用户购买决策」就是 67 分的全部原因，字段类问题则直接给字段名。

## 2. 全店抓取配方（3 分钟 74 件）

1. 列表页 `myseller.taobao.com/home.htm/SellManage/on_sale`（pageSize=20，翻页按钮 JS click 后等 3 秒）。
2. 每页 evaluate 一段 innerText 正则：`ID:(\d{10,})[^I]{0,120}?基础分\s*(\d+)\s*分[^扶]{0,10}扶优分\s*(—|[\d]+)`——一次拿 ID+双分。
3. 4 页合并 → `DELIVERY/scores_full_日期.json`（后续复查的对照基线）。
4. 分析口径：`base<100`（字段问题）、`fy<100`（转化项问题，大概率视频）、`fy=nc`（新品不用管）。

## 3. 筛选器坑位（列表页原生筛选不好使）

- 「质量分筛选」是 next-select 多选：**JS click 菜单项能选中 tag 但不触发查询**，必须再点「搜索」按钮才生效。
- **多选项 = AND 叠加**：同时勾「基础分60分以下」+「扶优分100分以下」结果是 0 件（交集为空），不是并集。清除用 `span.next-select-clear`。
- 比「下拉筛选→搜索」更快的替代：搜索框 placeholder 是「多个ID以逗号或空格分隔」，一次贴 5-10 个 ID 定点复查。

## 4. 修复路径对照表

| 症状 | 修法 | 实测 |
|---|---|---|
| 缺商品视频（扶优67） | 编辑页视频位上传/选视频（本地视频成品按商品 ID 命名直接对号） | 待验证——点击视频位未弹选择器，配方缺口见 10 号 §8 |
| 字段空缺 | 编辑页补字段后提交（品牌联想：fill 后必须点下拉联想项，光 fill 会被 React 丢弃） | 探头 PT100 属性补齐后 83→100（09-22→09-23 验证） |
| 类目 schema 没这个字段 | 无解，跳过 | 单耳 809355474895 无「材质」字段（其类目只有型号/背书卖点），交接假设不成立 |
| nc 未覆盖 | 不修，等出分；新品 3 天内推一单真实成交加速 | 配件新链 1085323474706 基础 100/nc/流量加速中 |

## 5. 复查节奏建议

- 批量改动后 48h 复查一轮（抓取脚本重跑 + 与基线 JSON diff，回退件自动浮出）。
- 「建议(n)」面板是权威：建议=0 且双分 100 = 该件在千牛维度已无事可做，剩余优化只在标题/SERP 侧。
