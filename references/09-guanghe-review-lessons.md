# 09 · 逛逛图文审核避坑：秒拒诊断与"干净内容"改造

> 2026-09-20 ~ 09-21 两天 4 篇图文连续被拒的完整复盘。含触发红线清单、图片重做方案、以及 OCR+坐标自动化通道在"编辑重发"场景下的全部坑。

## 一、先说结论

- **秒拒（提交后 1 分钟内被拒）= 机器初审**。列表时间戳更新但状态直接"公域审核不通过"即是。重提后正常排队会显示"公域审核中"。
- 驳回理由实测就两类：
  1. **"含过多营销及商业信息"** —— 正文带货话术；
  2. **"基础美观不达标，包括但不限于牛皮癣、不合理留白、画面杂乱、清晰度差、低质AI等"** —— 图片问题。
- **编辑机会有限**：被拒后"编辑重新提交"每篇只有一两次机会，用完锁死，连编辑页都进不去。第一次提交就要按"干净标准"来，别指望后面改。
- **全部内容清干净仍秒拒 → 查账号状态**。浏览器右下角出现"账号处于异常状态"标时，秒拒大概率是账号级风控，跟单篇内容无关（实测：正文零营销 + 图片全部重做后仍被秒拒）。

## 二、正文红线（逐项自查，全部实测命中）

| 触雷措辞 | 示例（脱敏） |
| --- | --- |
| 品牌名+规格清单连用 | "XX仪器的放料阀覆盖60到100四种口径，A/B/C型和上展式、下展式都有" |
| 供应/时效承诺 | "现货" · "48小时内发货" · "全规格成套供应" |
| 客服导流 | "口径拿不准的，把尺寸发给客服帮忙核对" |
| 互动引导（弱导流） | "选材质不清楚的，留言聊聊你的物料" |
| 高危结构 | 知识科普外壳 + 尾部带货段 = 最常见被拒形态 |

**对照**：同店两篇纯知识文（"速查表"体、"怎么选"体）全程零品牌零承诺，稳定通过。

**改法**：正文只留"怎么量 / 怎么选 / 怎么装"的知识本体；商业动线全部交给"**关联商品**"（挂商品是合规带货入口，可以留）。标题保持知识向（"XX怎么配？XX对照+XX要点"这类没问题）。

## 三、图片红线（"美观不达标"的元凶）

商品主图直接拿来当内容图，四条全占：

1. **全图平铺公司水印**（防盗图水印）—— 机器审盯"牛皮癣"第一眼；
2. **底部促销横幅**（"工厂直销 / 品质保证 / 免费开票"）—— 广告图特征；
3. **标注文字铺满**（尺寸线+数字+品名挤满画面）—— 画面杂乱；
4. **AI 生成图**有"低质AI"专项 flag —— 宁可程序渲染也别 AI 生成。

## 四、图片正确做法：程序渲染知识图表

用 PIL 直接渲染与标题呼应的知识表，四条红线全避开（无水印/无横幅/无杂乱/非AI生成），且清晰度天然达标：

- 规格 **1440×1440**，纯白底，微软雅黑（`msyh.ttc`/`msyhbd.ttc`），一主色 + 绿(良好)/橙(谨慎)/红(禁用)三态色；
- 内容示例：《介质适用对照表》（三组分区列表）、《使用三要点》（编号卡片）；
- 圆角面板 + 留白 + 底部一行小字免责（"基于通用化学相容性，特殊工况综合判断"）；
- **渲染完用 RapidOCR 自检一遍**：确认画面上只有预期文字，无任何残留水印/公司名。

要点伪代码：

```
img = Image.new("RGB", (1440,1440), "white")
d = ImageDraw.Draw(img)
d.rounded_rectangle(面板, radius=28, fill=(247,249,252))   # 浅灰圆角面板
d.text(标题, font=truetype("msyhbd.ttc", 78))
# 分组：色条+组名+条目；编号圆片+要点卡
img.save("out.jpg", quality=93)
# 自检：RapidOCR(out.jpg) 只应出现预期文案
```

## 五、自动化操作坑（OCR + 坐标通道，"编辑重发"场景）

1. **click.ps1 负坐标必须用命名参数** `-x 2071 -y -495`；位置参数 `2071 -495` 会被 PowerShell 当开关，实际点到 `(2071, 0)` 浏览器顶栏。
2. **首次点击被"窗口激活"吃掉**：窗口未聚焦时第一下只激活窗口。先点一下自己的标签页聚焦，再点目标。
3. **contenteditable 的 Ctrl+A 选不全**（多段节点）。可靠流程：点正文 → `^a` → `{DEL}` → 截图确认计数器归 `0/1000` → 粘贴 → **计数器数字 == 源文件字符数** 才算替换成功（字节级真凭据，比肉眼看内容可靠）。
4. **图片替换完整链路**（光合编辑器）：
   悬停缩略图 → 底部浮层「裁剪 | 替换」→ 点替换 → 素材面板「本地上传」→ Windows 对话框文件名框粘完整路径 → 回车 → **"上传结果"弹窗右下角「完成」**（橙底白字按钮，低倍 OCR 经常读不出，它在弹窗右下角、"1个文件上传成功"同一行右侧——**这是最容易卡住的一步**）→ 回到网格点**新卡片本体**（上传完的卡片要等网格重渲染后才可选中，位置会变）→ 按钮变「确定(1)」→ 点确定。
5. **路径文件用编辑器写**，别用 bash `printf` 生成——`\U`、`\r` 会被转义，路径悄悄毁掉（`C:\Users` 变 `C:Users`、`\rep` 变 `ep`）。
6. **定时/立即发布的验证靠像素取样**：定时栏常年挂一个默认时间（如"2026/09/21 16:34"），OCR 看不出选没选。提交前对单选钮坐标做 PIL 取色：**有饱和橙色像素=选中，全灰白=未选**。确认"定时"未选中再点"立即发布"（橙色按钮本身也可取色验证）。
7. **创作者声明\*（必填）**：选"个人观点，仅供参考"即可合规；同样可用像素取样确认已选。
8. 读数通道：截屏文件名每次必须唯一（Read 工具缓存同名旧图）；RapidOCR 本地读数（`ocr_shot.py`），视觉 MCP 超时/不支持图像时是唯一兜底。

## 六、秒拒后的排查顺序

1. 读驳回理由（列表行下方横幅或申诉入口，两类理由见上）；
2. 按第二节、第三节自检内容——正文清到纯知识、图片全部换渲染图；
3. **全干净仍秒拒 → 停止消耗编辑机会**，去千牛/卖家中心查账号体检与违规记录（"账号处于异常状态"= 账号级风控，改内容无用）；
4. 真有编辑机会时，优先换图（美观是机器初审第一道门槛），正文其次。
