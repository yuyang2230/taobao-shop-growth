# Phase 1 · AI对比池批量标题补词 SOP（Jev 两轮决策 + 安全闸）

> 来源：2026-09-22 某实验室仪器类淘宝C店实战——销量 TOP9 全量过流程，8 改 1 维持，7/7 提交回读通过。
> 前置：[02-title-optimization.md](02-title-optimization.md)（单件 60 字节公式）+ [10-bsk-channel.md](10-bsk-channel.md)（自动化通道）。本篇是"批量+决策引擎"的上层流程。

---

## 1. 选品：销量顺位扫描

后台全量扫描（见 10-bsk-channel §5）拿全部在售件的 累计销量/30日销量，按**累计销量降序**排队：
- 非实物链接（运费补差/返利补贴/定制专拍）**跳过**。
- 30日口径与累计口径第一名可能不同——按"销量最高"通用口径取累计第一，交付时注明两个口径。
- 已优化过的件（当日或近期）跳过，从台账查。

## 2. 单件闭环（五步，全店件循环）

```
① 侦察   编辑页读现标题+导购标题+类目属性+卖点+SKU结构（dump_item/field_read）
         + 该件主关键词 SERP 前10竞品标题（query_dump）
② Jev    构造决策请求（候选3~4个：现标题为对照组），跑两轮：
         第一轮选出候选 → 若标题票或执行票置信 <0.5，补定向复判（把三个候选的取舍点写透再问）
         执行票 <0.5 或"维持"胜出 → 该件不动（实测 P1 满字节件被 96% 票维持，正确）
③ 执行   批量脚本带三态安全闸（PRE/FILL/POST，见 10-bsk-channel §4）
④ 回读   提交后重载编辑页，字段值逐一比对
⑤ 台账   记录：改前/改后/字节数/Jev两轮票型/提交时间/成功页URL/回读结果
```

## 3. 候选标题构造要点（喂给 Jev 前的人工质检）

- 字节预算：1 汉字=2 字节、ASCII=1 字节，上限 60；**改后必须重新数一遍**（PS 脚本或手数，数错=提交被计数器打回或超限）。
- 补词优先级：**竞品高频通用词（配件/连接件）> 全称替换（旋蒸仪→旋转蒸发仪）> 类目属性实词（塑料抱箍）> 竞品句式词序对齐 > 工艺词（喷塑/压铸/可定制）**。
- 删除优先级：连词冗余（"实验室用"的"用"）> 重复词（第二个"法兰"）> 缩写（可换全称时）。
- **保真红线**：不确定的材质/场景/功能词**不进标题**。案例："单耳"件只有 2 字标题时，先用**图像识别 + 商品页问问AI + 店铺分类**三重核实它是什么（铝件压铸立柱固定夹套），再构造候选——凭空猜词 = 虚假宣传风险。

## 4. Jev 请求模板（实测格式）

```json
{
  "state": {
    "task": "批量标题补词·第N件/8(商品名) | 店铺：X | 目标：提升搜索命中与排名",
    "item": {"id":"...","现标题":"...","现字节":56,"销量":"累计504/30日16","属性":"...","导购标题":"..."},
    "searchReality": {"目标词":"...","现位次":"P3","竞品":["...","..."],"观察":"缺'配件'类通用词"},
    "constraints": "≤60字节（1汉字=2字节）；只改标题；表述真实；保留规格词"
  },
  "questions": {
    "newTitle": {"type":"choice","instructions":"终选最优新标题","criteria":{"A":"维持现标题(...)","B":"候选(...)","C":"候选(...)"}},
    "execute": {"type":"choice","instructions":"该调整是否值得执行提交（可逆、低成本）","criteria":{"执行":"...","维持":"..."}}
  }
}
```
- 两问设计（选什么 + 改不改）是**实测最稳结构**：标题票定方案，执行票定动作；两票都高置信才提交。
- 复判轮把首轮票型（"B=0.62/C=0.36 接近"）写进 context，只问"三选一定案"+"最终执行判断"。

## 5. 字段补齐变体（品牌/型号/导购标题）

标题 60 字节满、但品牌/型号空、导购标题无品牌时（编辑页明示"品牌信息有助于提升曝光"）：
- 品牌走 auto-complete 配方（10-bsk-channel §2，**fill 直接写值，禁 Enter**）。
- 型号是自由文本（0/100），与标题/SKU 规格口径呼应（如"60/75/80/100法兰放料阀"对应 17 档 SKU）。
- 导购标题 ≤30 字符，按平台推荐结构"品牌+品类词+利益点"（品牌+品类+功能，如「XX玻璃反应釜放料底阀」）。
- 同样走 Jev + 三态校验 + 回读。

## 6. 搜索定位图谱（交付物形态）

批量优化后产出定位基线，供 T+1~T3 复测对照：
- 表1 强项词（已占位）：关键词 × 本店件 × 位次 × 状态。
- 表2 空位/弱位词：现状 × 判断 × 已做动作。
- 附 AI 搜索适配实测（问问AI 回答质量 = 结构化信息完整度的免费探针）。
- 排入复查 cron（如 T+2 10:00），复测位次变化 + 新标题无回退检查。
