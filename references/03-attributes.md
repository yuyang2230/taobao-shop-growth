# Phase 1B · 属性补全（消除"流量受限"的根因）

> **本技能最重要的单点发现**：编辑页左侧"优化建议"里的红色 **错误(N)** 大多来自**商品属性必填项为空**。它不填，提交会被拦；即便绕过去，成功页也会挂着"发现 N 项问题 / **流量受限**"。实测补完必填属性再提交，"流量受限"提示直接消失——**对提分的效果比改标题更直接**。

## 1. 怎么发现问题

1. 编辑页左侧面板"优化建议"：红色 **错误(N)** = 必填项为空（必须处理）；黄色警告 = 建议项（尽量处理）
2. 提交后的成功页"检测结果"：
   - `SKU属性存在可优化项（流量受限）` → 去"销售信息"补 SKU 属性
   - `重要属性存在可优化项` → 去"基本信息"补商品属性
   - `缺少商品视频` → 不必"排期补拍"，走 [07-product-video.md](07-product-video.md) 免拍摄管线（主图→轮播/AI图生视频，轮播版兜底）
3. 千牛"商品巡检"能一次列出全店质量分问题商品 → 直接生成待办队列

## 2. 属性填写口径（实验室/设备类实测）

| 属性 | 口径 | 说明 |
|------|------|------|
| 适用场景 | 统一「实验室」；有细项选 科研实验/化工/制药/教学 | 与标题场景词一致，平台交叉验证 |
| 额定电压 | 220（V） | 国内设备必填项 |
| 驱动方式 | 电动 | 搅拌/泵类设备必填项 |
| 材质 | 采纳平台推荐值（如不锈钢、PTFE） | 推荐值就是行业主流，别自己造 |
| 品牌 | 保持现状不动 | 品牌库没有的品牌要商标证/授权才能新增，**别乱改** |

其他类目同理：**先看平台下拉推荐，有推荐就采纳，没推荐按行业标准词填**。

## 3. 两个白赚机制（每件编辑时都留意）

1. **「商品属性信息更新确定」弹窗**：打开编辑页时偶发，平台 AI 给出推荐属性值且默认勾选"采纳"——**直接点确定**。实测一个探头采纳后属性填写度 27% → 36%，零成本零风险。
2. **属性填写度百分比**：编辑页属性区顶部有"已填写 X%"，把它当 KPI，每件尽量往 80%+ 推。填写度直接影响商品质量分/扶优分。

## 4. 执行流程

```
进编辑页 → 若弹"属性信息更新确定"→ 点确定（白赚）
→ 看左侧"优化建议"红色错误数 N
→ 逐条补必填项（点错误条目会自动定位到对应字段）
→ 顺手补适用场景/材质等高价值建议项
→ 提交 → 成功页确认：错误清零、"流量受限"提示消失
→ 写回台账（记录：补了哪些属性、错误数 N→0）
```

## 5. 优先级建议

1. **32 件质量分问题商品**（巡检报告里的）批量补属性——比改标题的提分收益大
2. 已改过标题的商品回头补属性（只改标题的成功页会挂着"属性可优化/流量受限"）
3. SKU 属性（材质/规格维度）放在商品属性之后补

## 6. 常见坑

- 必填项为空点提交 → 被**拦截**并自动滚动到对应字段，补上再提交即可，**已填内容不会丢**，不用慌
- 品牌字段：搜不到的品牌就是品牌库里没有，乱填有侵权风险；要么申请（需商标证/授权书），要么保持现状
- 属性值尽量用**下拉可选值**而不是自由文本，机器可读性决定流量分发效率
