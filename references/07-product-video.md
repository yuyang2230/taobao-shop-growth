# Phase 1C · 商品视频（免拍摄管线）

> 成功页"缺少商品视频"几乎是每件商品都挂的项，默认解法是"排期补拍"——但小店没有拍摄资源，这一项就永远挂着。
> 本管线用**已有的商品主图**直接产出可用视频，全程零拍摄、零外拍团队。真实小店实测：首批 5 件一天内产出，全部上传千牛并提交成功，成功页"缺少商品视频"逐项消除。
> 两个版本：**轮播版（兜底，零失败率）** 与 **AI 图生视频版（观感更好，必须过 QC）**；AI 版不合格就退轮播版，不修。

## 1. 两个版本的定位

| 版本 | 做法 | 规格 | 特点 |
|------|------|------|------|
| **轮播版（主力交付）** | 3D 卡片轮播：商品的主图/SKU 图按 Y 轴翻转逐张展示，逐帧渲染后编码 | 720×720、无声 | 稳定、快、可批量，失败率≈0，永远是兜底 |
| **AI 版（可选）** | 主图喂图生视频服务，轻推镜头 | 720~1080p、约 5s | 运动自然、点击率更好，但画面内文字会被重绘 → 必须过 QC |

命名约定：轮播版 `{商品ID}.mp4`，AI 版 `AI_{商品ID}.mp4`。文件名=商品 ID 是整条管线能台账化、可续跑的关键。

## 2. 素材抓取（可选步骤）

- 淘宝对店铺商品数据有公开接口（`mtop.taobao.shop.*` 一类，接口名与参数会随版本变化，先抓包确认）：**匿名可拿店铺前 10 件**的完整数据（商品ID、标题、主图、SKU 图，图片 URL 可直接下载）。需要更多商品就必须带登录态；站内搜索页拿不到小店商品，别浪费时间。
- 更省事的路线：本地已有主图（商品列表页下载、或台账随附）就跳过抓取。

## 3. 轮播版生产（无依赖风险）

```
每张图 → PIL 渲染单帧（Y轴翻转过渡 + crop/pad 到 720×720）→ 逐帧写 rawvideo 管道 → ffmpeg 编码 mp4（无声）
```

工程提示：
- 逐帧用 Pillow 渲染、编码交给 ffmpeg 的 rawvideo 管道即可，不需要复杂转场库。
- 老版本 ffmpeg（2018 前后）**没有 xfade 滤镜、crop 表达式只在初始化时求值**——别和旧版较劲，"PIL 逐帧 + 简单编码"是兼容性最好的组合。

## 4. AI 版的关键坑（全在这里）

1. **喂图前必须裁掉文字区**：电商主图上下常压着营销文字，整图喂进去 AI 会把文字重绘成乱码。实测裁掉上 ~18% / 下 ~22% 的文字带，negative_prompt 里再禁"文字/乱码/变形"。
2. **QC 不可省**：抽帧 → 视觉模型三项判定——**货对版、无乱码、无变形**。即使做足了裁剪+负向词，仍有约 1/5 概率轻微乱码。**不合格直接弃 AI 版、交付轮播版**，不返工。
3. 限速：图生视频普遍 1~2 RPM，**必须串行**跑批；任务 ID 常有 base64 包裹，先解码再轮询结果。
4. 服务商可换：任何支持"图 + prompt + negative_prompt"的图生视频 API 都行（国内主流几家均可），不要把管线绑死在某一家上；prompt 保持简单——"轻推镜头，商品静止不变形"。

## 5. 交付与上传（与上传会话的接口）

- 维护一份《视频交付清单》：商品ID / 采用版本 / QC 结果 / 上传状态（未传 / 已传 / 成功）。即使生成与上传同一会话闭环，清单也逐件写回——中断后从台账续跑（管线支持"跳过已生成"）。
- 上传走 CDP 通道（见 [05-automation.md](05-automation.md) 通道二），实测 SOP：
  ① 编辑页「上传视频」按钮可能因虚拟滚动未挂载 → 重载页面后分段滚动找；
  ② 点开「选择视频」面板（内嵌素材库 iframe）→ iframe 内 `input[type=file]` 直接 `setInputFiles`，免系统文件对话框；
  ③ 视频发布到素材空间后，**视频列表网格不会自动刷新——必须 reload iframe** 新卡片才出现；
  ④ 勾选要点**视频卡片本体**（隐藏 checkbox 直接 check 无效）；
  ⑤ 「确认上传」后若弹智能剪辑浮层，选"无需优化，直接上传"；
  ⑥ 提交宝贝信息 → 成功页截图确认"缺少商品视频"检测项已消除。
- ⚠️ 上传前先按 05 通道二的覆盖层铁律隐藏悬浮的手机预览 iframe，否则面板点击全被拦截。
- 节奏：每批 5~10 件，传完一件写回台账一件；MP4、720p+、无声版就够用。

## 6. 什么时候判人工

- 主图本身就是详情页长图/带水印遮挡的，先回"我的商品"换主图（主图优化另属 Phase 1）再跑本管线。
- 上传位在当版千牛里找不到（版本迭代）→ 人工确认入口，别硬猜坐标。
