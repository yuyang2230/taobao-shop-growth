# Phase 1A · 标题重写（60 字节公式）

> 标题决定搜索入口。原则：**用满但不超 60 字节，重要词放前 16 个汉字，一个标题覆盖"核心词 + 型号 + 材质 + 场景 + 品类 + 配件"六段信息**。

## 1. 硬性规则（千牛 v2 编辑器实测）

| 字段 | 限制 | 要点 |
|------|------|------|
| 宝贝标题 | **≤60 字节**（1 汉字 = 2 字节，即最多 30 汉字） | 目标用满 55~58 字节；手机端超 16 汉字折叠，**核心词必须出现在前 16 字** |
| 导购标题 | ≤30 字符（15 汉字） | 手机推荐流实际展示位，**小店普遍全店空白，逐件补** |

## 2. 六段式公式

```
核心词 + 型号/规格 + 材质 + 场景词 + 品类词 + 配件词
```

- **核心词**：买家搜索量最大的那 1~2 个词，放最前（如"旋转蒸发仪"而不是"小型电动升降…"）
- **型号/规格**：B2B 买家按型号搜索，型号必须进标题（DF-101S、RE-2000/3000/5000）
- **材质**：不锈钢 / 四氟 / 玻璃——既过滤精准流量又是必填属性的素材
- **场景词**：统一口径，如实验设备类一律"实验室"（与属性里的适用场景一致，平台会交叉验证）
- **品类词 + 配件词**：给跨类目搜索留入口（"反应釜冷凝器管夹卡箍配件"）

### 错词双写技巧
行业里广泛误写的词（如温度传感器 PT100 常被写成 TP100），新标题**两个都写**：`PT100温度传感器TP100`——正确词拿专业买家，误写词捡误搜流量。

**从案例提炼的三条铁律**：
1. **空格和标点都是浪费**——中文标题不需要分隔符，紧排即可，每件都能多塞 1~2 个关键词
2. **SKU 名称就是关键词金矿**——档位（防爆/球磨口/宝塔嘴）、规格（2L-200L）、材质全部值得进标题
3. **标题必须和 SKU 对得上**——先在编辑页读 SKU 全档位，再拟标题；材质没证据就不写（台账说聚四氟、店铺分类说铝件时，宁可不写）

## 4. 执行要点

1. 从台账队列取一件，**先在编辑页看清原标题全文**（列表页标题可能截断，台账记录可能失真）
2. 新标题先按公式草拟、数好字节数（汉字×2 + 字母数字×1），再进编辑器
3. 改完**必须 zoom/截图核对输入框实际内容与字数计数器**，再提交
4. 导购标题同场顺手补（15 汉字内：核心词 + 型号 + 一句卖点）
5. ❌ 禁改：价格、库存、SKU、运费模板（护栏，见 SKILL.md）

## 5. 什么算改好了

- 字节数 55~58，核心词在前 16 字
- 覆盖 ≥4 段信息（六段式）
- 型号无笔误；有行业误写词的做了双写
- 导购标题非空
- 提交成功页无"标题相关"检测项
