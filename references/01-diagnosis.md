# Phase 0 · 店铺诊断

> 目标：30 分钟内摸清店铺家底，产出《店铺体检报告》和《商品台账》两份文件，后续所有优化从台账驱动。

## 1. 检查清单（千牛卖家中心逐项看）

### 1.1 体验分（千牛首页 / 店铺评分入口）
四个维度逐项记录，找出**唯一短板**：

| 维度 | 看什么 | 常见问题 |
|------|--------|----------|
| 宝贝质量 | 描述相符 | 低分多因详情页信息不足 → Phase 2 补 FAQ |
| 物流 | 发货/物流速度 | 配件类目通常不差 |
| 服务保障 | 售后、纠纷 | **老店常见短板，拖全店权重** |
| 真实体验分 | 总分 + 超过同行百分比 | 4.8 以上且超同行即健康 |

⚠️ 服务保障/服务分偏低的根因通常是**旺旺响应慢 + 售后处理慢**，属于人工活，自动化替代不了——诊断报告里要明确标出来让店主自己改（目标：3 分钟内首响）。

### 1.2 店铺基建（3 个高频老化点）
- **首页**：只有 banner 轮播、没有商品陈列区的老首页 = 白白浪费首页流量。改法：加"热销配件 / 主力设备 / 新品"至少三个商品分区。
- **旺铺模板**：还在用多年前的老模板（如 2012 版）就升级到当前默认模板，手机端适配免费拿。
- **保证金**：确认足额，不足会影响部分流量权益。

### 1.3 商品结构
在售列表（`myseller.taobao.com → 我的商品 → 出售中`）抓取：商品ID、标题、价格、库存、30 日销量、质量分标记。记录时注意：
- 标题截断的（超长堆砌）标记 ⚠️，进标题重写队列
- 30 日 0 销 + 高客单的标记为"待内容运营"（这类靠搜索+询盘，不靠冲动下单）
- 非实物链接（补贴/赠品类）标记 ❌ **永不修改、永不自动化碰它**
- ⚠️ 列表页标题↔ID 可能因截断看错行，执行阶段一律**用商品ID搜索定位**复核

### 1.4 联系方式露出（B2B 类目加测）
看详情页/客服自动回复里挂的联系方式：
- **虚拟号（170/171 等开头）会让 B2B 买家警惕**，换成真实手机号并注明"微信同号"
- 高客单类目买家习惯电话/微信询价，这一项直接影响询盘转化

## 2. 产出文件模板

### 《店铺体检报告.md》
```
# 店铺体检报告 <日期>
- 体验分：X.XX（超同行 X%）｜质量 X / 物流 X / 服务保障 X ← 短板
- 层级：Lv.X｜保证金：足额
- 首页：□有商品陈列 □仅banner｜旺铺模板：□新版 □老版
- 商品总数：X 件（标题问题 X / 质量分问题 X / 0销量高客单 X）
- 服务分结论：人工项——旺旺首响目标 3 分钟内
- 本周优先级：1.____ 2.____ 3.____
```

### 《商品台账.md》
```
| 商品ID | 标题 | 价格 | 30日销 | 问题标记 | 状态 | 完成时间 |
```
台账是唯一进度依据：每完成一件立刻写回，多会话/多天接续全靠它。

## 3. 诊断结论 → 行动映射

| 诊断发现 | 进哪个队列 |
|----------|-----------|
| 编辑页有红色错误/必填属性空 | 属性补全队列（最高优先） |
| 标题短、无参数、无场景词 | 标题重写队列 |
| 首页无陈列、老模板 | 店铺基建（一次性人工改） |
| 服务分低 | 店主人工：响应速度 + 售后 |
| 高客单 0 询盘 | 内容运营队列（逛逛 + 站外长文） |
